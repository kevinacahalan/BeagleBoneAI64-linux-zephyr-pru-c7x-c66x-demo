# Yocto

Kas config and the `meta-ai64` layer live here. Build `ai64-demo-image` from the repo root. The commands are in the top-level README. Podman and docker both work. Set `KAS_CONTAINER_ENGINE` to `podman` or `docker`. Unset, kas-container uses docker when that client is installed, and otherwise podman. `kas-container build` does not write the SD card.

```
wget -O kas-container https://raw.githubusercontent.com/siemens/kas/5.5/kas-container
chmod +x kas-container
KAS_BUILD_DIR=yocto/build ./kas-container build yocto/kas/ai64-poky.yml
```

- `kas/ai64-poky.yml` — includes the copy of TI's poky-wrynose kas file in `layers/meta-ai64/kas/`, machine `beaglebone-ai64`, distro `poky`, target `ai64-demo-image`
- `layers/meta-ai64` — recipes that compile the Linux demo, the Zephyr R5F firmware, the three ICSSG0 firmwares, and the DSP hello images, and install extlinux, the sysconf first-boot service, and the USB gadgets
- `sources/`, `downloads/`, `build/` — generated by kas-container, not committed
